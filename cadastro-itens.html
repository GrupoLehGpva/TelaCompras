Entrar

Só quem cadastra no GR tem acesso. O login é pessoal: cada item e cada fornecedor fica registrado com o nome de quem mexeu.

Cadastrando como

Novo item

Copie do GR, do jeito que está lá. O item aparece no formulário de compras assim que for salvo.

Antes de cadastrar, confira duas coisas:
  1. O item precisa já estar criado no GR. Use o código e o nome exatamente como estão lá. Item que não existe no GR não vira ordem de compra.
  2. Cuidado com duplicidade. Veja se o item já não está no formulário com outro nome ou outro código. Enquanto você digita, a tela mostra os parecidos — se um deles for o mesmo item, não cadastre.

Excluir item

O item some do formulário de compras na hora. Pedido que já usou o item não muda. Se ele continuar no GR, a importação do catálogo não traz ele de volta — para voltar, cadastre o mesmo código de novo e escolha reativar.

Cadastrados aqui, aguardando o GR

Até o item aparecer na planilha do GR e o catálogo ser importado de novo, ele fica nesta lista e dá para corrigir. Depois disso, quem manda é o GR.

Novo fornecedor

Copie do GR, do jeito que está lá. O fornecedor aparece para o setor de Compras assim que for salvo.

Antes de cadastrar, confira duas coisas:
  1. O fornecedor precisa já estar criado no GR. Use o código de lá — é por ele que a ordem de compra encontra o fornecedor no GR.
  2. Cuidado com duplicidade. Busque o fornecedor no quadro de baixo antes. A tela não deixa salvar um CPF ou CNPJ que já está cadastrado.
